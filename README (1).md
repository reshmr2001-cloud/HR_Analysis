# HR Analytics Dashboard | Power BI Project

## Overview

This project presents an interactive **HR Analytics Dashboard** developed using **Power BI** to analyze workforce data and provide actionable insights into employee demographics, hiring trends, workforce distribution, and remote work adoption.

The dashboard enables HR professionals and business stakeholders to monitor key workforce metrics, identify trends, and support data-driven human resource planning and decision-making.

---

## Business Problem

Organizations generate large volumes of employee data, but transforming that data into meaningful business insights is often challenging.

The objective of this project is to:

* Analyze workforce composition
* Monitor employee distribution across departments and locations
* Evaluate remote work adoption
* Track hiring trends over time
* Provide interactive HR dashboards for business decision-making

---

## Project Objectives

* Analyze employee demographics
* Measure remote vs headquarters workforce
* Identify department-wise employee distribution
* Analyze state-wise employee concentration
* Monitor hiring trends
* Build interactive KPIs for HR reporting

## Key Business Insights

* The organization employs **22,214 employees**.
* **25%** of employees work remotely, while **75%** work from headquarters.
* The **Engineering** department has the largest workforce.
* **Ohio** has the highest employee concentration.
* Hiring has shown a steady upward trend over time.
* Technical departments contain significantly larger workforces than administrative departments.
* The average employee age is **38.43 years**, indicating an experienced workforce.
